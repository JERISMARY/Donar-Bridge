# Donar-Bridge
Blood Donor Connect ❤️🩸

Live demo: https://jerismary.github.io/Donar-Bridge/

A straightforward web page that aims to help connect patients with verified blood donors nearby in times of need. The focus is on simplicity and usefulness — making it easy for someone to register as a donor or request blood when required. 


🎯 Project Overview

Blood Donor Connect is a small, responsive web app built with HTML, CSS, and JavaScript (no backend). It allows users to:

Register themselves as a volunteer donor

Find nearby verified donors

Submit a blood request

Read simple instructions to use the app safely and responsibly

All the data and interaction in this demo are handled locally in the browser, meant as a portfolio piece and concept prototype rather than a full production system. 


🧠 Motivation

The idea came from wanting to build something that could be practical and socially helpful, even in a small way — especially considering how valuable timely blood donations are in emergencies. Building this also helped me practice web development fundamentals and think about user flows and UX writing in forms and instructions. 
Jerismary

🛠️ Technologies Used

HTML — Structure of the site

CSS — Design and layout

JavaScript — Client-side interactivity (forms, button behavior)

No backend server or database is used — all interactions are frontend only (browser based). 
Jerismary

📌 Features

✔ Friendly and simple UI
✔ Register as a donor
✔ Request blood support
✔ Instructions for safe use
✔ Contact info section (placeholder content) 


📋 How to Use

Open the Live Demo
Visit https://jerismary.github.io/Donar-Bridge/

Read Instructions
Follow the guidelines on how to register and request blood safely. 


Register or Request

Click Register as Donor if you want to volunteer

Click Request Blood if you need donor support 

⚠️ This is a front-end prototype — it doesn’t currently save or send data to a server. It’s mainly meant to show concept and design.
